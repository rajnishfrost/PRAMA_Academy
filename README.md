# Prama Academy

Full-stack educational platform for a cognitive-skills institute serving children aged 4–13.

🔗 **Live:** https://pramaacademy.com

## Features
- Interactive learning tools — **Math Worksheet Generator**, **Flash Anzan**
- **Admin panel** with role-based access control (RBAC)
- Student-facing UI used daily

## Tech Stack
- **Frontend:** React, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Deployment:** self-managed infrastructure
